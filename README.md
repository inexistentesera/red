# Blue X Ultimate Framework
Sistema modular de monitoramento PvP para experiências Roblox.

## Estrutura
- `CoreEngine`: Gerenciamento de estados.
- `CombatManager`: Lógica de segurança e zona segura.
- `UI`: Interface neon responsiva.

## Instruções
1. Importe os arquivos no Explorer do Roblox Studio.
2. Coloque os módulos em `ReplicatedStorage` ou `ServerScriptService` conforme a lógica.
3. Configure os eventos de combate seguindo a API do seu jogo.
